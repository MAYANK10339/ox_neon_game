OX NEON - ANDROID APK INSTALL GUIDE
====================================
1. Transfer OX_Neon_Game.apk to your Android phone via WhatsApp, Telegram, Google Drive, or USB cable.
2. Tap the APK file to install.
   - If you already have Version 1, Android will show "Do you want to update this app?". Tap "Update".
   - If installing for the first time, allow "Install unknown apps" when prompted.
3. Open OX Neon and enjoy smooth 60-120 FPS offline & online multiplayer!

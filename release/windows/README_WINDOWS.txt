OX NEON v2.0 - WINDOWS PORTABLE EDITION
=======================================
1. Choose your executable:
   - OX_Neon_Game_v2.exe (Recommended: Voice Chat, Text Chat, 3x3, 5x5, 10x10 grids, ~13 MB)
   - OX_Neon_Game_v1.exe (Classic 3x3 edition preserved, ~13 MB)
2. Double-click to launch on Windows (PC or Laptop). No installation required!
3. Multiplayer Voice & Text Chat:
   - Host generates 4-digit code (choose 3x3, 5x5, or 10x10).
   - Friend joins on Android Phone or Windows PC.
   - Click "Chat" to send text messages.
   - Hold "Hold to Talk" mic button to record and send voice notes!
4. Native exit: Click the EXIT button in the main menu to close.

OX NEON - WINDOWS PORTABLE EDITION
===================================
1. Double-click OX_Neon_Game.exe to launch the game on Windows (PC or Laptop).
2. No installation required. Runs natively with full offline AI, Pass & Play, and WebRTC cross-platform multiplayer!
3. To exit, click the EXIT button in the main menu or close the window.

CROSS-PLATFORM MULTIPLAYER:
- Host on Windows PC -> Share 4-digit code -> Enter on Android phone -> Play together live!
- Host on Android phone -> Share 4-digit code -> Enter on Windows PC -> Play together live!
